How a profile HMM scores a sequence

A substitution matrix says what any alanine is worth anywhere. A profile says what an alanine is worth at position 4 of this family, and what it costs to skip that position or to squeeze a residue in beside it. Viterbi finds the best path through that model, and the path is a single trace through a single grid: each profile position owns three rows — match, insert, delete — so this is the Session 4 matrix with more rows, not a new idea. The profile is built from the five-sequence alignment the Session 5 slides already use: AGLSP AGLTP RGISP AALSQ AALSP.

Things worth typing into it: AGLSP, the consensus, which is all match states; AGLP, a residue short, where a delete state lights up; AGLSAP, a residue too many, which forces an insert; and WWWWW, five tryptophans, which the family has never seen. Then switch the pseudocounts from background-proportional to flat +1 and look at WWWWW again: it now outscores the real consensus. A flat pseudocount gives an unseen tryptophan the same probability as any other unseen residue, and the score then divides by how rare tryptophan is in the background, so never having seen one becomes a reward. That is the Ala-versus-Trp point the Why pseudocounts matter slide makes, here as a number you can watch move.

The transition probabilities are a readable toy set rather than fitted ones, and the model has no begin or end state beyond the single entry: this is for seeing the mechanism, not for scoring real families — HMMER does that, in the lab. See also the alignment matrix and how BLAST works.
