Then click Select Kernel → Colab (top right) and run the cells; see the Setup page. Before you start, get the latest version of the notebooks: in VS Code, Command Palette (Ctrl+Shift+P or Cmd+Shift+P) → Git: Pull. Or open the file yourself: in VS Code, press Ctrl+P (Cmd+P on a Mac) and type .

The first time only: get the course notebooks

  1. Install VS Code, git, and in VS Code the extensions Python, Jupyter and Google Colab.
  2. Clone the course notebooks into VS Code
    VS Code asks where to save them (about 100 MB) and then offers to open the folder.
  3. Copy the folder's full path into the box above. This browser remembers it.
