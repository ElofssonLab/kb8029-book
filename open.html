Download the notebook

Open the downloaded file in VS Code, or any editor that opens .ipynb files, and run the cells. The notebook downloads the data it needs by itself.

If the lab needs a GPU

Mainly Sessions 9–12. With the notebook open in VS Code, click Select Kernel (top right) → Colab → Auto Connect, or pick a runtime with a GPU, and sign in with a Google account. The code then runs on a Colab machine while you keep working in your own editor. The Setup page has the details, and it was shown in the first lecture.
