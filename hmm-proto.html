Viterbi against a profile HMM — prototype

One question only: do the three state types read as one matrix? Each profile position owns three rows — match, insert, delete — so the path is a single trace through a single grid, the way Session 4 taught it, instead of three grids with arrows flying between them. The profile is built from the five-sequence toy alignment the Session 5 PSSM slides already use: AGLSP AGLTP RGISP AALSQ AALSP.

Try AGLSP (the consensus, all match states), AGLP (a residue missing — watch a delete state light up), AGLSAP (a residue too many — an insert state), and WWWWW. Then switch the pseudocounts to flat +1, the notebook's scheme, and look at WWWWW again: it outscores the real consensus, because a flat pseudocount gives an unseen tryptophan the same probability as any other unseen residue while the background then divides by how rare tryptophan is. That is the Ala-vs-Trp point the "Why pseudocounts matter" slide already makes, here as a number you can watch change.
